# 证明义务清单

本文件把定理梯拆成可审计义务。每条义务在完成前不得在论文中写成已证结论。

## T1 语义等价

状态：拟证明。

- `PO-T1-1` 有限性：从 `A0` 和 `A1` 推出状态空间有限。
- `PO-T1-2` 事件合法性：所有事件保持容量守恒、路线合法和预约合法。
- `PO-T1-3` BAS 忠实性：加工完成后资源仍被持有，直到 unload/handoff/release。
- `PO-T1-4` 闭包处理：证明闭包终止；若不合流，则用集合后继而非函数。
- `PO-T1-5` Petri 映射：在 `A7` 子类中证明 `phi` 与 firing 对应。
- `PO-T1-6` 反向映射：只有在无额外 Petri 标识歧义时证明 `psi`。

计算验证：

- 枚举所有小模型稳定状态，检查每个后继满足容量守恒。
- 对可投影子类比较 LTS trace 与 Petri firing trace。

## T2 死锁证书

状态：拟证明。

- `PO-T2-1` 从操作死锁构造至少一个封闭阻塞核。
- `PO-T2-2` 从最小封闭阻塞核推出对应工件集合无法自主进展。
- `PO-T2-3` 证明全局死锁需要覆盖所有未完成活动；否则只得局部死锁。
- `PO-T2-4` 多容量 residual 计算正确。
- `PO-T2-5` 替代后继、软预约和多 AGV 选择全部纳入阻塞条件。
- `PO-T2-6` 单实例受限子类中的简单环充分性与必要性。

计算验证：

- 生成 `DeadlockCertificate` JSON，要求每条等待边有 job、resource、need、hold/reservation 和 residual 字段。
- 对 C1/C3 断言简单环或 WCC 不能单独触发死锁结论。

## T3 虹吸桥

状态：拟证明。

- `PO-T3-1` 给出 IMS 子类到 Petri place/transition 的构造。
- `PO-T3-2` 证明最小 closed core 映射到最小或包含最小致死 siphon。
- `PO-T3-3` 证明致死 siphon 反向映射到可审计阻塞核的条件。
- `PO-T3-4` 给出一般情形失败的最小反例。
- `PO-T3-5` 标记 S3PR 可用条件与超出条件。

计算验证：

- 对 Petri 子类枚举 siphon，与 core 做包含/最小性检查。
- 对 AGV/预约投影反例检查 false negative。

## T4 结构充分条件与阈值

状态：拟证明。

- `PO-T4-1` 定义获取偏序覆盖所有关键资源。
- `PO-T4-2` 证明封闭核会诱导严格上升闭合链。
- `PO-T4-3` 用有限严格偏序反证 circular wait 不存在。
- `PO-T4-4` 明确该命题不推出标准 nonblocking 或几乎必然完成。
- `PO-T4-5` 定义双向制造岛参数族。
- `PO-T4-6` 用穷举网格寻找阈值公式或最小反例。

计算验证：

- 对满足偏序的 C2 网格断言无封闭核。
- 对 C5 双向/删回流成对模型记录首个死锁参数。

## T5 概率层

状态：文献基线 + 拟证明。

- `PO-T5-1` 构造有限生成元 `Q`，并分块为 `T,D,F`。
- `PO-T5-2` committor 方程：`h_D=1`，`h_F=0`，`Q_TT h_T = -Q_TD 1`。
- `PO-T5-3` 平均吸收时间：`Q_TT tau = -1`。
- `PO-T5-4` 敏感性：`Q_TT partial_theta h_T = - (partial_theta Q_TT) h_T - (partial_theta Q_TD) 1`。
- `PO-T5-5` Doob-`h`：`q^h_ij = q_ij h_j / h_i` 只在 `h_i>0`，对角元设为负行和。
- `PO-T5-6` 解释边界：Doob-`h` 是条件路径动力学，不是控制器。

计算验证：

- 线性系统残差小于预注册容差。
- DES 仿真置信区间覆盖精确 CTMC 概率。

## T6 控制层

状态：拟证明。

- `PO-T6-1` 划分可控与不可控事件。
- `PO-T6-2` 最大不变安全集固定点必须对所有不可控后继闭合。
- `PO-T6-3` 最大许可 nonblocking supervisor 保留所有能到 marked completion 的安全行为。
- `PO-T6-4` 结构干预 hitting set 需要 core 全集完备。
- `PO-T6-5` 若干预产生新 core，必须迭代反例生成。
- `PO-T6-6` 概率控制给出风险预算递归可行性或保守界。

计算验证：

- 对小 LTS 输出禁用事件集、保留状态数和不可控闭合检查。
- 对概率控制输出风险预算残差和 Pareto 候选点。
