# Literature Matrix

Status values are defined in `SEARCH_PROTOCOL.md`. `FULLTEXT-THEOREM` requires
full-text inspection plus a reproducible theorem, section, appendix, or equation
locator. Lower-evidence rows are not proof sources for theorem statements.
The phrase `not a complexity result` is a complete non-applicability record for
papers whose role is structural/control modeling rather than asymptotic
complexity; it is a closed classification.
